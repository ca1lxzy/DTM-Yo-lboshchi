# 🎯 DTM Yo'lboshchi

Abituriyentlar uchun DTM tayyorgarlik yordamchisi. Static sayt (HTML/CSS/JavaScript), server va bazasiz ishlaydi.

## Muammo
11-sinf o'quvchilari mock testlarda natija olishadi, lekin:
- maqsadli universitetga yetish uchun necha ball yetishmayotganini aniq bilishmaydi;
- kuniga o'qiydigan vaqtini qaysi fanga qancha ajratishni bilmaydi (ko'pincha yaxshi biladigan fanni takrorlayverishadi);
- rivojlanish sur'ati imtihon kuniga yetarlimi yoki yo'qligini ko'ra olishmaydi.

## Yechim
| Bo'lim | Vazifasi |
|---|---|
| Ball hisoblagich | 90 savol, 189 ball tizimi bo'yicha (1-fan 3.1, 2-fan 2.1, majburiy fanlar 1.1) |
| Maqsad va reja | O'tish ballidan farqni hisoblaydi, kunlik soatni fanlarga olinmagan ballga qarab taqsimlaydi |
| Mock jurnal | Natijalar tarixi, grafik va chiziqli regressiya asosida imtihon kuni uchun prognoz |
| Zaif mavzular | Mavzularni daraja bo'yicha ustuvorlashtiradi, bajarilganini belgilash |

## Ishga tushirish
`index.html` faylini brauzerda oching. Qo'shimcha o'rnatish shart emas.

## GitHub Pages orqali joylash (Demo link uchun)
1. GitHub'da yangi repository yarating, `index.html` va `README.md` ni yuklang.
2. Settings → Pages → Branch: `main` → Save.
3. Berilgan `https://username.github.io/repo-nomi` havolani "Demo link" maydoniga kiriting.

## Texnologiyalar
HTML5, CSS3 (Grid/Flexbox), vanilla JavaScript, Canvas API, localStorage.
